# Blank table template

Place one user-owned blank `.docx` template in this directory. The template should retain clause numbers, table titles, structure, borders, merged cells, fixed wording, and formatting, while measured values, dates, equipment IDs, tester names, and remarks should be blank.

The first `.docx` alphabetically is used unless `BLANK_TEMPLATE_FILE` is specified in `.env`.

Do not commit confidential or copyrighted company templates to a public repository.
